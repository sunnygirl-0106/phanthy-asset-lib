## 一、演示动线（不变）

**第一步「剧本分析」** → 一次性生成全部空壳资产（角色 / 角色造型 / 服装 / 场景 / 道具），
全部带提示词、**无图、无参考图**。

**第二步「资产生成」** → 只生成 角色 / 服装 / 场景 / 道具，**每份 4 张图，第 1 张默认定稿**，
其余 3 张陈列在右侧候选区。生成完成的同时，**自动给角色造型挂上参考图 = 定稿角色图 + 定稿服装图**。

**第三步「批量生成角色造型」** → 只生成角色造型，同样 4 张，第 1 张默认定稿。

**贯穿全程的不变量**
> 不允许存在「有候选图但无定稿」的资产。取消定稿后不许退出详情页，退出前必须重选一张；
> 新建资产同理，强制选定一张作为定稿。

## 三、给豆包的生成要求

### 铁律

> **同一份资产的 4 张图，必须是「同一个主体的四次生成结果」，不是四个不同的东西。**
> 这是整套演示的地基 —— 用户看到的是「AI 对同一段提示词给出的四个候选」，选一张定稿，其余留作候选。

- **角色**：同一个人的四张脸。同性别、同年龄、同发型、同一套打底衣、同一种背景与打光。差异只在五官细微不同、角度或表情的轻微变化。
- **服装**：同一套衣服的四次呈现。版型、配色、材质完全一致，差异只在褶皱、角度、细节。
- **场景**：同一个客厅的四次呈现。差异在机位、光线浓淡。
- **道具**：同一部手机的四次呈现。差异在角度、光泽。
- **角色造型**：同一个角色穿同一套服装的四次呈现。**脸必须认得出是同一个人**。

### 统一规格

竖版 **3:4，1024×1365** 左右；**写实摄影风**；自然光；现代都市基调（干净、明亮、生活感）。

### 逐份提示词方向

| 资产 | 提示词方向 |
|---|---|
| **阿杰** | 亚洲男青年，25–30 岁，短黑发，清瘦，**白色圆领 T 恤 + 浅色长裤的中性素模打底**，纯浅灰背景，正面半身，均匀柔光，平静表情 |
| **苏可** | 亚洲女青年，23–28 岁，黑色长发，**白色圆领 T 恤 + 白色长裤的中性素模打底**，纯白背景，正面半身或全身，均匀柔光，平静表情 |
| **西装** | 深藏青男士两件套西装，**无人穿着的服装展示**（衣架悬挂或平铺），白色背景，可见面料纹理与剪裁细节 |
| **睡衣** | 浅色棉质女士家居睡衣（长袖上衣 + 长裤），柔和纯色或细印花，**无人穿着展示**，白色背景，面料柔软质感 |
| **客厅** | 现代都市公寓客厅，布艺沙发、木质茶几、落地窗、暖色台灯，午后自然光斜射，**无人**，宽幅取景 |
| **手机** | 一部现代智能手机，深色机身，特写，置于浅色台面，屏幕熄灭或微亮，自然光反射 |
| **阿杰·西装造型** | **阿杰这张脸**，穿上那套深藏青西装，室内或都市街头，半身或全身，脸清晰可辨 |
| **苏可·睡衣造型** | **苏可这张脸**，穿上那套睡衣，客厅场景内，半身或全身，脸清晰可辨 |

> 建议顺序：先出阿杰和苏可的素模，定下两张脸；再拿这两张脸去出对应的造型图，这样"同一个人"最容易保住。
