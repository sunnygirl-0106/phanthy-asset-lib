## 〇、这次在改什么（一句话）

**给「定稿」一个明确的产品含义——授权——然后围绕这个含义补齐三个缺口：自动定稿的边界、预览图上的参考图/取消定稿入口、手动新增资产。**

0807 把「定稿」做成了一个纯粹的操作（选一张当封面）。这一版给它一个语义：

> **定稿 = 授权这张图被系统和别人引用。**

这一句话同时解释了三件原本要分开记的规则：
- 为什么未定稿的图不能被选作参考图（`CanvasAssetPanel` 第 146 行 `.filter(a => a.status === 'done')`）
- 为什么未定稿的资产不能沉淀到团队库、贡献到广场（`assertDone`）
- 为什么定稿必须由用户亲自点，系统不能代劳

**0807 里有两条设计要撤回**（用户评审时推翻，理由成立）：

| 0807 的设计 | 撤回原因 |
|---|---|
| 待定稿资产删到只剩 1 张 → 自动定稿 | 定稿是授权，系统不能因为"没得选了"就替用户发授权。用户一次生成七八张再删到剩一张，仍然要他自己点。 |
| 「★ 定稿」徽章只在候选池 ≥ 2 张时显示 | 定稿在项目库是常驻概念，不是"有得选时才出现的临时标记"。团队库/广场不显示，是因为那里每一张都已经是定稿。 |

## 一、自动定稿的边界

### 1.1 规则

> **自动定稿只发生在生成那一刻，且同时满足三个条件：**
> ① 本批只产出 1 张
> ② 资产原本没有定稿（`cover === ''`）
> ③ 资产原本候选池是空的（这是它第一次出图）
>
> **一旦资产进入待定稿，就再也不会自动跳出去**——删到只剩一张不会，追加上传一张也不会。

条件 ③ 是关键，别漏。没有它会出现这种意外：用户有一份 4 张候选的待定稿资产，从本地补传了 1 张图，结果这张补传的图被自动设成了定稿——他明明还在挑。

**为什么"批量生成 1 张就自动定稿"是成立的**：剧本分析后的统一生成是标准化动作，系统一份只出一张，用户**没有选择可做**，此时代他拍板不算越权。用户主动一次生成 4 张，是探索行为，选择权必须留给他。

## 二、修一个 0807 埋下的坑：待定稿资产没有底图

### 4.4 「取消定稿」

**服务层** —— `src/services/assetService.ts`，在 `setFinal`（第 103–107 行）后面加：

```ts
/**
 * 取消定稿（0808）：资产从成品退回待定稿，图都还在池子里，只是撤回"可被引用"这个授权。
 * 撤回后这份资产：不能被选作参考图、不能沉淀到团队库 / 贡献到广场、卡片打「待定稿」。
 * 已经被别的资产挂为参考图的 url 快照、以及已经拷出去的副本，都不受影响。
 */
export function unsetFinal(source: Asset): Asset {
  if (!source.cover) throw new AssetRuleError('这份资产还没有定稿')
  if (!source.candidates?.length) throw new AssetRuleError('候选池为空，无法取消定稿')
  return { ...source, cover: '', status: 'pending' }
}
```

**store** —— `src/store/useStore.ts`，紧挨 `runSetFinal`（第 568–586 行附近）加：

```ts
runUnsetFinal: (assetId) => {
  const { world, currentUserId } = get()

  if (!user || !asset) return fail('数据不存在')

  try {
    const next = unsetFinal(asset)
    set((s) => ({

    }))
    return ok('已取消定稿，这份资产暂时不能被参考或沉淀')
  } catch (e) {
    return fromError(e)
  }
},
```

接口声明（第 140 行 `runSetFinal` 旁）：

**不做二次确认**（用户明确要求）——图都还在，重新点一下「设为定稿」就回来了，代价极低。

  const { world, currentUserId } = get()
  const user = findUser(world, currentUserId)
  const project = world.projects.find((p) => p.id === projectId)
  if (!user || !project) return fail('数据不存在')
  if (!canDirectReuse(user, project)) return fail('你没有权限在这个项目里新建资产')
  if (category === 'other' || category === 'audio') return fail('这个类目不支持手动新建')
  const nm = name.trim()
  if (!nm) return fail('名字不能为空')
  if (libraryHasSameName(world.assets, 'project', projectId, nm)) {
    return fail(`该项目已有「${nm}」，请换个名字`)
  }
  const id = makeId('asset')
  const asset: Asset = {
    id, category, name: nm, scope: 'project', scopeId: projectId,
    status: 'empty', cover: '', prompt: '', fields: {}, tags: [],
    createdAt: Date.now(),
  }
  set((s) => ({ world: { ...s.world, assets: [...s.world.assets, asset] } }))
  return { ok: true, message: id }
},
